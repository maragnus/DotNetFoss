# Screen Buffer

Cells array = Columns x Rows x 32-bits

* 8-bits: ASCII character
* 8-bits: Foreground (Palette)
* 8-bits: Background (Palette)
* 1-bit: Bold
* 1-bit: Faint
* 1-bit: Italic
* 1-bit: Underline
* 1-bit: Blink
* 1-bit: Inverse
* 1-bit: Hidden
* 1-bit: Strikeout

## Palette
Palette is a table 0-255
0-15: Standard ANSI colors
16-255: Either ANSI-256 or ANSI-Truecolor
